# CostaBlancaFinder AI — Real Data Sources

## Objetivo

Preparar la integración futura de fuentes reales de datos inmobiliarios, turísticos y geográficos.

## Fuentes previstas

- Idealista
- Fotocasa
- Habitaclia
- OpenStreetMap
- Google Places
- Datos turísticos oficiales
- AEMET / clima
- Eventos locales

## Estrategia

### Fase 1
Dataset manual controlado.

### Fase 2
Scraping controlado y respetando condiciones de uso.

### Fase 3
APIs oficiales y automatización.

### Fase 4
Pipeline diario de datos reales.

## Nota legal

Antes de automatizar cualquier fuente, se revisarán sus condiciones de uso, límites técnicos y viabilidad legal.
