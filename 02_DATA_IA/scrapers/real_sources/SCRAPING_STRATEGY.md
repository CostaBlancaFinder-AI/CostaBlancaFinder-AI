# Scraping Strategy

## Principio

CostaBlancaFinder AI debe obtener datos de forma responsable, trazable y escalable.

## Prioridad de fuentes

1. APIs oficiales
2. Datos abiertos
3. Fuentes públicas permitidas
4. Scraping controlado
5. Captura manual validada

## Riesgos

- bloqueo por plataformas
- cambios HTML
- restricciones legales
- datos duplicados
- datos falsos
- falta de actualización

## Buenas prácticas

- respetar robots.txt
- evitar scraping masivo
- guardar fuente y fecha
- no copiar contenido protegido innecesario
- priorizar APIs
- validar duplicados
- mantener trazabilidad
